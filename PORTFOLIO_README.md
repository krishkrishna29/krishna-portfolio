# Krishna Prakash Isabi - Portfolio Website

A highly modern, trendy, premium 3D animated portfolio website showcasing Krishna Prakash Isabi's skills as a Software Tester & Java Developer.

## ✨ Features

### 🎨 Design
- **Dark futuristic theme** with neon blue, purple, and cyan gradients
- **Glassmorphism UI** with backdrop blur effects
- **Floating particles background** for depth and immersion
- **3D CSS transforms** with Framer Motion animations
- **Responsive design** for mobile and desktop
- **Inter font** for modern, professional typography

### 🚀 Sections

#### 1. Hero Section
- Full-screen immersive landing
- 3D rotating geometric shape with gradients
- Animated gradient background with glowing orbs
- Typewriter animation cycling through achievements
- Two glowing CTA buttons with 3D hover effects
- Social media links with glassmorphism style
- Smooth scroll indicator

#### 2. About Me
- Large glassmorphism card with 3D tilt effect on mouse movement
- Professional avatar with gradient overlay
- Comprehensive background information
- Animated counter cards showing achievements

#### 3. Technical Skills
- 6 skill cards with 3D rotation on hover
- Custom gradient icons for each skill
- Animated progress bars with percentage
- Glow effects on hover

#### 4. Featured Projects
- 6 project cards with 3D flip animation on hover
- Realistic project content based on testing background

#### 5. Education & Training
- Animated timeline with glowing dots
- BCA degree and QSpiders training details

#### 6. Contact Section
- Fully functional contact form with validation
- Success toast notifications
- Social media links

## 🛠️ Tech Stack

- **Frontend**: React 19
- **Styling**: Tailwind CSS
- **Animations**: Framer Motion
- **UI Components**: Shadcn UI
- **Icons**: Lucide React
- **Toast Notifications**: Sonner

## 📝 Customization

### Update Personal Information

Edit the following files:
- `/app/frontend/src/components/Hero.jsx` - Name, title, social links
- `/app/frontend/src/components/About.jsx` - Bio and stats
- `/app/frontend/src/components/Contact.jsx` - Email, phone, location

### Update Projects & Skills

Edit `/app/frontend/src/components/Projects.jsx` and `/app/frontend/src/components/Skills.jsx`
